# 莫比乌斯环实验室

基于 [Three.js](https://threejs.org/) 的交互式莫比乌斯环演示：支持沿带宽等分裁剪、条带拉开分离、边界描边动画，以及边界拉伸成圆。

在线访问：将仓库部署为 GitHub Pages 后，打开站点根路径即可（本地开发见下方）。

## 功能概览

| 模块 | 说明 |
|------|------|
| **带宽裁剪** | 原状 / 二等分～五等分，沿环向逐步剪开，条带呈金色金属质感 |
| **拉开它们** | 裁剪完成后拖动滑块，各条带沿曲面法向在空间中分离、缠绕 |
| **边界描边** | 从单一起点沿拓扑边界连续绘制橙色发光边线 |
| **边界拉伸** | 拉伸系数 0→1，边界由空间曲线渐变为平面圆环 |
| **显示模式** | 环+边界 / 仅边界 / 仅环 |

## 本地运行

页面使用 ES Module，需通过 HTTP 访问（不能直接 `file://` 打开）。

```bash
# Python 3
python3 -m http.server 8080

# 或 Node.js
npx serve .
```

浏览器打开：<http://localhost:8080>

## 使用说明

### 1. 带宽裁剪

1. 选择 **二等分**～**五等分**（或保持 **原状** 查看完整单条带）。
2. 使用 **沿环裁剪** 滑块或 **自动裁剪**，观察剪刀沿环向剪开条带。
3. 裁剪到 100% 后，拖动 **拉开它们**，观察各条带如何在空间中扩张分离。

> 二等分剪开莫比乌斯环后，会得到相互缠绕的双环结构，与经典拓扑实验一致。

### 2. 边界描边

1. 调节 **已描长度** 或点击 **自动描边**。
2. 橙色光点从边界起点出发，沿唯一边界路径绘制成闭合边线。
3. 可通过 **显示模式** 切换是否同时显示环面。

### 3. 边界拉伸

1. 调节 **拉伸系数**：`0` 为原始边界形态，`1.0` 为完美平面圆环。
2. **动态演示** 可自动往复播放拉伸动画。
3. 拉伸时环面沿带宽方向自然收缩，不会出现内外边之间的直线连接。

## 技术说明

- **渲染**：Three.js `WebGLRenderer` + `OrbitControls`
- **曲面**：参数化莫比乌斯环 \((R + v\cos\frac{u}{2})\cos u,\ (R + v\cos\frac{u}{2})\sin u,\ v\sin\frac{u}{2}\)
- **边界**：商空间 \((u,v)\sim(u+2\pi,-v)\) 上的单条闭合曲线；拉伸时映射为圆上同一圈角度
- **裁剪**：按带宽均分条带，沿 \(u\) 方向渐进显示几何体，条带间留缝隙
- **依赖**：通过 import map 从 jsDelivr CDN 加载 Three.js r170，无需构建步骤
