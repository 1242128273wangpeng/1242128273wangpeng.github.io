# Möbius Band · 莫比乌斯环

基于 Three.js 的 H5 立体莫比乌斯环演示，参数可实时调节。

## 运行

本地需通过 HTTP 访问（ES Module 限制），任选其一：

```bash
# Python 3
python3 -m http.server 8080

# Node.js (npx)
npx serve .
```

浏览器打开：<http://localhost:8080>

## 参数说明

| 参数 | 含义 |
|------|------|
| 主半径 R | 环中心到带中心线的距离 |
| 带宽 w | 环带的宽度 |
| 周向/径向分段 | 曲面网格精度 |
| 自转速度 | 绕 Z 轴自动旋转 |
| 金属度 / 粗糙度 / 色相 | PBR 材质外观 |

## 交互

- 左键拖拽：旋转视角
- 滚轮：缩放
- 右键拖拽：平移
- 面板按钮：线框模式、暂停旋转、重置视角
